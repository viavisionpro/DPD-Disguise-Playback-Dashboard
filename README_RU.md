# Disguise Playback Dashboard

[English](README.md)

**DPD** — нативный плагин мониторинга воспроизведения для **Disguise Designer**.
Запускается из папки Plugins проекта и подключается автоматически. Редактировать
настройки, устанавливать дополнительную среду или запускать отдельный сервер
не требуется.

## Виды интерфейса

**Compact** открывается внутри **Designer GUI**. Показывает основной и
второстепенный транспорты, активные слои, следующие медиа и таймеры.
Цветовые маркеры слоёв соответствуют **Layer Colour Rules** Disguise, включая
правила трека. При одном транспорте второстепенная строка скрыта.

![Compact внутри Disguise Designer GUI](assets/screenshots/DPD_Compact.png)

**Advanced** и **Simple** открываются **в браузере** через веб-интерфейс Designer.
Advanced показывает Previous / Active / Next, метаданные секций и FPS Director.
Simple оставляет Active / Next и более крупные таймеры.

![Advanced в браузере](assets/screenshots/DPD_Advanced.png)

![Simple в браузере](assets/screenshots/DPD_Simple.png)

## Установка

1. Скачайте **DPD_v0.5.9_Plugin.zip** из [Releases](https://github.com/viavisionpro/DPD-Disguise-Playback-Dashboard/releases/latest).
2. Распакуйте папку **DPD-0.5.9** в **Plugins** проекта. При обновлении сначала
   закройте DPD и уберите его предыдущую папку из Plugins.
3. Откройте проект и выберите **DPD - Plugin** в меню **Plugins** Designer.

При нескольких транспортах выберите основной при первом запуске — проект
запомнит выбор. Изменить его можно в диагностике: клавиша **D** или
**DIAGNOSTICS** в статусной строке.

Для доступа из браузера откройте **IP Director**, затем выберите DPD в
веб-интерфейсе Designer. По умолчанию открывается Advanced; переключатель
Advanced / Simple находится внизу. Устройству нужен доступ к сети Director.

Целевая версия — **Designer r31+**; размер окна и цвета подтверждены на **r33.2.4**.
Диагностика открывается внутри текущей страницы. Изменение высоты окна Designer
пока разрешает. DPD не управляет воспроизведением; выбор транспортов сохраняется
в проекте. Показываются слои Video и Generative; время для статичных изображений
и генеративного контента приблизительное. Динамик обозначает наличие аудиодорожки.
