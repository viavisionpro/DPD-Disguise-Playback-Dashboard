# Disguise Playback Dashboard

[English version](README.md)

**DPD** — дашборд для мониторинга воспроизведения в **Disguise Designer**.
Он работает в браузере и получает актуальные данные от **Директора по локальной
сети**. DPD запускается на Windows или macOS; открыть интерфейс можно на том же
компьютере или другом устройстве в сети.

DPD отображает только слои категорий **Video** и **Generative**.
Программа показывает состояние воспроизведения, не управляя Designer.

## Что отображает DPD

- Основной и второй таймлайны: названия треков, режим воспроизведения и статус ON AIR.
- До трёх активных слоёв основного таймлайна и один слой второго.
- Названия, типы и яркость слоёв; имена медиафайлов, если они доступны, теги
  выбранных версий вида `v.2` и индикаторы встроенного аудио.
- Прошедшее и оставшееся время, крупный обратный отсчёт и предстоящие медиа.
- Данные текущей и следующей секций: TC, MIDI, OSC и заметки в Advanced;
  длительность следующего клипа в Simple.
- Состояние выходов Директора — FADE UP, FADE DOWN или HOLD — и FPS Директора в Advanced.
- Название проекта, часы, дату и состояние подключения с диагностикой потоков данных.

У оригинальной версии медиа тег не отображается. Слои **DISABLED** исключаются;
фильтрация MUTE не поддерживается. Значок аудио означает наличие аудиодорожки
в файле, а не слышимый звук на выходе. Таймеры изображений и генеративного
контента приблизительные.

## Установка и запуск

Нужны запущенная сессия **Designer r30+** и доступ к её API по сети.
На Windows установите **Python 3.10+** с компонентом **Python Launcher (`py`)**.
На macOS установщик использует подходящий Python или автоматически установит
локальную копию. Для **WINDOW** нужен Google Chrome.
Первоначальная установка требует доступа в интернет.

1. Скачайте **Runtime ZIP** со страницы [Releases](https://github.com/viavisionpro/DPD-Disguise-Playback-Dashboard/releases/latest) и полностью распакуйте его.
2. Откройте **Windows/** или **macOS/** и запустите **INSTALL**.
3. Запустите **DEMO**, чтобы проверить DPD без Designer.
4. Настройте **config.json**, как описано ниже.
5. Запустите **START** для обычного браузера или **WINDOW** для отдельного окна Chrome.

Файлы запуска имеют расширение `.bat` на Windows и `.command` на macOS.
Держите терминал открытым; **Ctrl+C** останавливает DPD.
Если macOS блокирует скачанный файл запуска, сначала попробуйте открыть его,
затем разрешите запуск в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.

## Настройка подключения

Редактируйте корневой **config.json**, когда DPD остановлен.

| Параметр | Значение |
| --- | --- |
| `designer.host` | IP Директора. По умолчанию `127.0.0.1`, если Designer работает на том же компьютере. |
| `designer.port` | Порт HTTP API Designer. По умолчанию `80`. |
| `timelines.main.transport` | Точное имя основного Transport Manager. По умолчанию `default`. |
| `timelines.aux.transport` | Точное имя второго Transport Manager. По умолчанию `second`. |
| `server.bind` | По умолчанию `0.0.0.0`: прослушивание всех локальных интерфейсов. Для доступа только с этого компьютера — `127.0.0.1`. |
| `server.port` | Порт веб-интерфейса DPD. По умолчанию `8080`. |

На компьютере с DPD откройте **http://127.0.0.1:8080/**, на другом устройстве
в локальной сети — **http://IP-КОМПЬЮТЕРА-DPD:8080/**.
Переключение Advanced / Simple находится внизу страницы.

При обновлении распакуйте архив в новую папку и перенесите свой **config.json**.
Существующие настройки сохраняются. При запуске из исходников используется
**.private/config.json**, если корневого конфига нет.

## Диагностика

Нажмите **D** или **DIAGNOSTICS**; **Esc** закрывает окно.
Полный лог находится в **.private/logs/dashboard.log**.
Если DEMO работает, а данные Designer не появляются, проверьте IP Директора,
порт API и имена Transport Manager. Для восстановления зависимостей запустите
**INSTALL** повторно.
