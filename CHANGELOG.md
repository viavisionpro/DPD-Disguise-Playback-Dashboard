# Release history

## v0.4.13 — 2026-10-23

- Advanced and Simple browser views for Video and Generative layers on two
  Disguise Designer timelines.
- Windows and macOS launchers with dependency setup, demo mode and a Chrome
  window mode. Windows relaunch replaces a verified DPD instance.
- Media filenames and selected non-original version tags, including dotted
  versions. Wider filename columns in both views.
- Disabled-layer filtering, Director identity, output state, FPS and diagnostics.
- Local-network access enabled by default with server.bind=0.0.0.0.
- English and Russian user guides with screenshots.
